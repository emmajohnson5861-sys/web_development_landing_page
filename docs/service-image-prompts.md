# Service images

Generated with the built-in imagegen tool. PNG originals were encoded as WebP for the website.

Final assets live in `public/media/services/`: `custom-generated.webp`, `commerce-generated.webp`, `applications-generated.webp`, `platforms-generated.webp`.

### custom

Use case: product-mockup. Asset type: services image for Algofort web development agency. Generate a polished premium editorial 3D product photograph in portrait format, approximately 2:3. Subject: a sculptural silver desktop monitor displaying a beautifully designed architecture studio website, with a small orange geometric sculpture beside it; bold editorial layout with one large architecture photograph and restrained abstract text blocks. Cohesive visual series: warm off-white studio backdrop, matte charcoal, brushed aluminum, warm gray, subtle orange accents matching #ff6716. Soft directional studio lighting, believable shadows, tactile materials, refined art direction. Keep the main device centered with generous margins so it remains visible in both a narrow portrait crop and a horizontal center crop. No people, no brand logos, no watermark, no oversized lettering; interface text should remain unobtrusive and nonessential. Beautiful realistic website-agency advertising photography, not clip art.
