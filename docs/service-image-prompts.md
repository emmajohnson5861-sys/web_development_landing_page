# Service images

Generated with the built-in imagegen tool. PNG originals were encoded as WebP for the website.

Final assets live in `public/media/services/`: `custom-generated.webp`, `commerce-generated.webp`, `applications-generated.webp`, `platforms-generated.webp`.

### custom (Bespoke Web Experiences)

Use case: product-mockup. Asset type: services image for Algofort web development agency. High-end editorial commercial photograph in portrait 2:3 format of a bespoke creative web development workstation in a luxury design atelier. In the center, a premium ultra-slim metallic studio display showcases an award-winning custom agency website with avant-garde layout, striking 3D sculptural graphics, bold typography, and subtle vibrant orange interactive accents. The workstation is in an elegant architectural studio with dark fluted wood walls, warm designer ambient lighting, and soft directional glow. On the dark smoked wood desk sits an angled iPad Pro displaying interactive UI wireframes, a minimalist black aluminum keyboard, and a sleek stylus on a leather tray. Luxurious creative agency atmosphere, photorealistic, sharp focus, rich tactile textures, cinematic depth of field, no watermarks.

### commerce

Use case: product-mockup. Asset type: services image for Algofort web development agency. Generate a polished premium editorial 3D product photograph in portrait format, approximately 2:3. Subject: a premium e-commerce storefront on a floating slim tablet surrounded by a ceramic vase and a sculptural skincare bottle; the screen shows a tasteful product photography grid and orange shopping controls. Cohesive visual series: warm off-white studio backdrop, matte charcoal, brushed aluminum, warm gray, subtle orange accents matching #ff6716. Soft directional studio lighting, believable shadows, tactile materials, refined art direction. Keep the main device centered with generous margins so it remains visible in both a narrow portrait crop and a horizontal center crop. No people, no brand logos, no watermark, no oversized lettering; interface text should remain unobtrusive and nonessential. Beautiful realistic website-agency advertising photography, not clip art.
